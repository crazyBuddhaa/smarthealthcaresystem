Faculty clinic calendar

Reserve clinic dates for one faculty at a time.

Admin only
When at least one block is configured, automatic appointments and administrator rescheduling will only offer dates assigned to the student’s faculty. Use the same start and end date for one day, or use a Monday–Friday range for a faculty week. Blocks cannot overlap.
